# Portfólio - Bruno Garibaldi

Landing page pessoal desenvolvida como projeto do curso +PraTi, utilizando HTML, CSS e JavaScript puro.

## 🚀 Funcionalidades

- Design responsivo (desktop e mobile)
- Alternância entre modo claro e escuro
- Formulário de contato com validação
- Preenchimento automático de cidade/estado via CEP (API ViaCEP)
- Navegação com scroll suave

## 🛠️ Tecnologias

- HTML5
- CSS3 (Custom Properties, Flexbox, Grid)
- JavaScript (Vanilla)
- API ViaCEP

## 💻 Como rodar o projeto

1. Clone o repositório:
   git clone https://github.com/brunofgaribaldi/portfolio-bruno.git

2. Abra o arquivo `index.html` no navegador (ou use a extensão Live Server no VS Code)

## 🌿 Estrutura de branches

- `main`: versão estável do projeto
- `develop`: branch de desenvolvimento
